01. Industry Context

Why AptiQuiz? The Problem with Legacy Quizzes

Traditional quiz platforms collapse under high-concurrency placement exams and fail to gamify learning.

02 / 10

❌ Legacy Monolithic Platforms (Kahoot, Quizizz)

  • •
    Single Process Bottleneck: Node.js single-thread event loop blocks when hundreds of users submit simultaneously during collegiate hiring drives.
  • •
    High Latency & Sync Drifts: WebSockets lag over 250ms+, causing unfair point distribution and timing discrepancies.
  • •
    Trivial Question Formats: Shallow trivia lacking engineering depth, quantitative formulas, code comprehension, and verbal aptitude.
  • •
    No Stage/Auditorium Optimization: Mobile-only viewers without real-time broadcast displays or host stage telemetry.
Fragile architectures lead to dropped connections and unfair ranking in placement drives.

⚡ The AptiQuiz Solution & Vision

  • ✓
    Horizontal Sharding (Worker Cluster): Rooms run across 5 dedicated Node processes (Ports 8001–8005) orchestrated via Port 8000.
  • ✓
    Strict Real-Time Synchrony: Sub-50ms bidirectional Socket.io broadcast guarantees synchronized countdown clocks for every contender.
  • ✓
    Industry-Grade Academic Curricula: 300 calibrated aptitude questions covering Quantitative, Logical, Systems, Probability, and Verbal.
  • ✓
    Esports Broadcast System: 4K Projector views, audio ticks, live Recharts player progression, and dynamic QR quick-invites.
Designed specifically for engineering colleges, hackathons, and corporate placement drives.

02. Infrastructure

Scalability Architecture: 5-Worker Micro-Cluster

Decoupled gateway routing with process isolation and persistent cloud state synchronization.

03 / 10
Tier 1: Ingress Layer

Master Gateway (:8000)

Acts as the reverse proxy and room allocator. Hashes room codes (`CRC32(code) % 5`) to assign sessions to specific workers, eliminating single-process saturation.

POST /api/rooms -> Worker #3
Tier 2: Realtime Engine

5-Worker Cluster (:8001-8005)

Independent Socket.io micro-daemons managing in-memory room state, socket heartbeat tables, monotonic time ticks, and instantaneous scoring computations.

Workers 1..5: Process Isolation
Tier 3: Persistence & Sync

Supabase PostgreSQL

Relational storage storing question vaults, user performance telemetry, persistent room records, and historical leaderboard leaderboards with Row Level Security (RLS).
